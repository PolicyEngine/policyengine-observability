Pin `opentelemetry-instrumentation-fastapi` and `opentelemetry-instrumentation-httpx` to `>=0.64b0`. Earlier versions raise `AttributeError: '_IncludedRouter' object has no attribute 'path'` on FastAPI >= 0.137 `include_router` routing, which turned every CORS preflight `OPTIONS` request into a 500 for consumers that enable FastAPI instrumentation.
