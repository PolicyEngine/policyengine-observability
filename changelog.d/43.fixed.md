Record an operation or request that ends in `KeyboardInterrupt` with the outcome `interrupted` at WARNING instead of `error` at ERROR, and leave it out of the error count metric. Its span, and any span that ends in `KeyboardInterrupt`, keeps an unset status and gets the attribute `policyengine.outcome` set to `interrupted`. The exception still propagates unchanged, and every other exception is recorded as before. The Flask adapter no longer adds a 500 status code to such a request, and the FastAPI adapter now passes the `KeyboardInterrupt` to the request record instead of recording the request as successful; either record carries only a status code set or sent before the interrupt. A span is now closed, and the previous trace context restored, even when adding its exception event or status fails, and a failure to add the exception event no longer stops the status from being set. On Modal, a preemption reaches the running function as `KeyboardInterrupt`, and Modal then runs the same input again.
