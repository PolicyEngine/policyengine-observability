Record an operation or request that ends in `KeyboardInterrupt` with the outcome `interrupted` at WARNING instead of `error` at ERROR, and leave it out of the error count metric. Its span, and any span that ends in `KeyboardInterrupt`, keeps an unset status and gets the attribute `policyengine.outcome` set to `interrupted`. The exception still propagates unchanged, and every other exception is recorded as before. The Flask and FastAPI adapters no longer add a 500 status code to such a request, so its record carries a status code only if one was already set or sent; the FastAPI adapter previously recorded it as successful. A span is now closed, and the previous trace context restored, even when adding its exception event or status fails. On Modal, a preemption reaches the running function as `KeyboardInterrupt`, and Modal then runs the same input again.
