Replace the implicit global runtime and version 1 decorators with an explicit
runtime returned by `configure`. Version 2 adds runtime-bound operations and
spans, idempotent Flask and FastAPI request adapters, explicit HTTPX and Python
logging instrumentation, bounded Modal Cloud Logging delivery, authenticated
OTLP export, and allowlisted cross-service correlation. Consumers must replace
removed version 1 imports before upgrading. Logging and OTel now have separate
shutdown timeout settings, shutdown failures are contained per subsystem, and
process recovery replaces inherited locks and asynchronous delivery state.
